Assignment 01

Hindi Literary Stopwords

Abstract. This project develops an experimental Hindi stopword resource for literary text processing. It contains 39 selected grammatical words and uses Python to remove them while preserving meaningful vocabulary such as प्रकृति, नदी, वन and जीवन.

View this project's GitHub repository

Project overview

Objective

To explore how selected grammatical words can be removed from Hindi text without removing meaningful literary vocabulary.

Methodology

  1. Created a curated list of 39 Hindi stopwords.
  2. Loaded the list from stopwords.txt.
  3. Applied Unicode NFC normalization using Python.
  4. Used whitespace-based tokenization to identify stopwords.
  5. Tested the function on sample Hindi sentences.

Sample text and output

Original text:

प्रकृति और मनुष्य का संबंध बहुत गहरा है।

Cleaned text:

प्रकृति मनुष्य संबंध बहुत गहरा।

Removed stopwords:

और, का, है

Project files

  • Python implementation
  • Hindi stopword list
  • Example and testing
  • Methodology and limitations

Limitations

This is an experimental resource, not a universal Hindi NLP standard. Its current list is limited to 39 words, and whitespace-based tokenization cannot capture every linguistic variation. Further testing on a larger Hindi poetry corpus is required.

Assignment 02

Hindi Poetry RAG: Ecological and Cultural Elements

Abstract. This project explores how Retrieval-Augmented Generation (RAG) can retrieve and interpret ecological and cultural references in selected passages from Kamayani by Jaishankar Prasad. It uses multilingual text embeddings, semantic retrieval, and Gemini to generate Hindi answers grounded in retrieved passages.

View this project's GitHub repository

Project overview

Research Focus

  • Flora and fauna in Hindi poetry
  • Rivers, water and landscapes
  • Natural elements and seasons
  • Cultural and metaphorical meanings
  • Human–nature relationships

Methodology

  1. Prepared 15 selected passages from three sargs of Kamayani.
  2. Divided the passages into 43 text chunks.
  3. Generated 384-dimensional multilingual embeddings.
  4. Implemented semantic retrieval using cosine similarity.
  5. Generated context-grounded Hindi responses using Gemini.
  6. Conducted preliminary manual retrieval evaluation using 12 judgments.
  7. Analysed flora and fauna keyword frequencies and created a Gephi co-occurrence network.

Flora and Fauna Frequency Analysis

The chart presents the frequency of selected ecological terms identified in the experimental poetry corpus.

Tools and Technologies

Python, Google Colab, Pandas, Sentence Transformers, Gemini API, Gephi and GitHub.

Limitations

This is an experimental prototype based on 15 selected passages from three sargs, not the complete Kamayani text. Keyword-based analysis may miss synonyms, metaphorical references and inflected word forms. Retrieval evaluation is preliminary and based on manual relevance judgments.

Assignment 04

Critical Literary Text Analyst

Abstract. This project develops a reusable LLM skill for analysing Hindi poetry through ecological imagery, cultural elements, symbolism and human–nature relationships, using selected passages from Jaishankar Prasad's Kamayani.

View this project's GitHub repository

Visible assignment work

Research Focus

How can an LLM be guided to analyse ecological and cultural dimensions of Hindi poetry through evidence-based interpretation?

Methodology

  • Designed a reusable Markdown-based SKILL.md instruction file.
  • Defined ecological, cultural, symbolic and human–nature analysis criteria.
  • Created sample prompts and a built-in demonstration passage from Kamayani.
  • Tested the skill using an AI assistant and documented its sample output.

Project Files

  • SKILL.md
  • Sample Prompts
  • Sample Analysis

Tools

Markdown, GitHub, ChatGPT/Gemini and Hindi literary text.

Limitations

The skill provides structured AI-assisted interpretation, not definitive literary scholarship. Interpretations require textual verification and wider literary context.

Assignment 04

Synthetic Reading of Premchand's कफ़न

Abstract. This project explores Munshi Premchand's short story कफ़न through partial reading, researcher reflexivity, AI-assisted thematic extraction and critical literary interpretation. It examines how poverty, hunger and social marginalisation intersect with human sensitivity, particularly through the neglect of Budhiya.

View this project's GitHub repository

Project overview

Research Question

How does Premchand's कफ़न explore the relationship between poverty, hunger, social marginalisation and human sensitivity, particularly through the neglect of Budhiya?

Methodology

  1. Divided the complete story into three approximately equal parts.
  2. Selected beginning, middle, ending and random sentence-units from each part for partial reading.
  3. Developed an initial reflection, research problem and researcher positionality.
  4. Prepared a detailed prompt for AI-assisted thematic extraction.
  5. Organised extracted themes and textual evidence in JSON and Python formats.
  6. Created a bar chart comparing the number of extracted evidence excerpts across themes.
  7. Interpreted the findings using Cultural Materialism and Intersectionality.

Theoretical Frameworks

  • Cultural Materialism: poverty, hunger, labour and material conditions.
  • Intersectionality: overlapping effects of caste, class and gender.

Visualization

Project Files

  • Complete story corpus
  • Partial reading selections
  • AI analysis prompt
  • Thematic extraction (JSON)
  • Python theme data
  • Findings and interpretation

Limitations

AI-generated themes and interpretations require human verification. The visualization shows counts of extracted textual evidence excerpts, not actual theme frequency or importance. Budhiya's limited narrative voice also restricts the interpretation of her personal perspective.

02

Portfolio reflection

Across these assignments, I explored how digital methods can support the study of Hindi language and literature. The projects move from preparing a small Hindi stopword resource, to building a retrieval-based system for examining ecological and cultural elements in poetry, and designing an AI-assisted literary analysis skill. The Synthetic Reading of Premchand's कफ़न extends this work by combining partial reading, researcher reflection, AI-assisted thematic extraction and critical interpretation. Together, these projects helped me understand that digital tools can organise and make textual evidence easier to examine, but they do not replace close reading, contextual knowledge or human judgement. I also learned to document methodological choices and limitations rather than presenting computational or AI-generated results as definitive conclusions.

Methods note

The projects used Python and Google Colab for text processing and analysis, a retrieval-augmented generation workflow for selected Hindi poetry passages, an LLM skill written in Markdown, and AI-assisted thematic extraction for कफ़न. The methods included Unicode text handling, stopword filtering, text chunking, semantic retrieval, keyword analysis, co-occurrence visualisation and evidence-based thematic interpretation. The corpus and passage selections were limited in scope; AI-generated interpretations and extracted quotations require checking against the source text. The visualisation in the कफ़न project counts extracted evidence excerpts, not the actual frequency or importance of themes. These limitations are part of the interpretation.
